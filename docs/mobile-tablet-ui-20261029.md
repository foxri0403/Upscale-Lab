# 모바일·태블릿 웹 UI 개선

작업 브랜치: `gusrb03/mobile-tablet-ui`. 기존 `gusrb03/explore-details`의 미커밋 작업을 `b1104b4`에 보존하고 main에 `c0279d9`로 병합·푸시한 뒤 분기했다.

## 화면 구성

- 1100px 이하에서는 메뉴를 접이식으로 제공한다. 처음에는 닫히며 화면 이동·바깥 선택·Esc로 닫을 수 있다. 열린 동안 본문은 inert로 처리하고 데스크톱 메뉴 표시 설정은 보존한다.
- 작업실의 고정 높이·좁은 3열 배치를 세로 흐름으로 바꾼다. 미리보기 아래에 설정·저장·내보내기를 배치하고 페이지 스크롤로 모든 기능에 접근한다. 600px 이하에서는 편집 도구 여섯 개를 3열·2행으로 표시한다.
- 도구의 ARIA 방향은 화면 배치와 함께 갱신한다. 계정 아이콘은 작은 화면에서도 접근성 이름을 유지한다.
- 긴 이미지·기기·모니터 이름, 버튼, 해상도·주사율과 배경화면 제목은 좁은 화면에서 줄바꿈한다. 기기 카드 헤더의 고정 flex 높이와 줄 수 제한을 해제해 내용 겹침을 방지한다. 큰 태블릿 가로 화면도 이름을 줄바꿈한다.
- 이미지 목록·검색/필터·탐색 상세·계정/정보 대화상자·다운로드·이미지 추가·로그인/소개 화면의 폭과 줄바꿈을 조정한다. 입력 글자 크기와 터치 영역을 확보하고 안전 영역 및 동적 화면 높이를 사용한다.
- 1100px보다 넓은 화면의 작업실 열 구성은 유지한다. API·인증·DB·GPU 처리·연결 앱 기능은 변경하지 않는다.

## 검증

기존 작업 보존 전 백엔드 전체 xUnit 203건, 웹 로컬 테스트 53건 및 빌드가 통과했다. 웹 UI 검증에는 실제 사용자 계정·이미지 대신 임시 정적 데모와 샘플 데이터를 사용했다. API·GPU·S3·기기 OS는 변경하지 않았다.

브라우저에서 320×568, 360×800, 390×844, 568×320, 600×960, 768×1024, 820×1180, 1024×768, 1180×820, 1366×1024 화면을 확인했다. 최종 소스는 내 이미지·탐색·기기 관리·작업실 각각을 320/768/1366px에서 렌더링 완료 후 검사한 12개 조합에서 가로 넘침과 표시 글자 잘림이 없었다. 입력 필드의 긴 편집 값과 화면 읽기용 숨김 제목은 일반적인 편집·접근성 동작으로 유지한다.

접이식 메뉴 열기·페이지 선택 후 닫힘, 작업실 도구 전환, 자르기·배경 분리·필터·태그·이미지 정보, 계정 창의 세로/가로 모드, 탐색 상세와 로그인 화면을 확인했다. 작은 화면의 도구는 모두 표시되고 설정·저장 버튼은 페이지 스크롤로 접근 가능하다. 브라우저 검증 기록과 휴대폰·태블릿 캡처는 무시되는 `artifacts/mobile-tablet-ui/`에 보존한다. 물리 기기별 OS 키보드·센서·노치 동작의 실기기 측정은 포함하지 않는다.
