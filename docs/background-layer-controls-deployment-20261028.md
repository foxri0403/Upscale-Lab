# 배경 분리 설정 패널 수정 배포

2026-10-28 운영 주소: [Upscale Lab](http://13.124.225.10).

## 반영 내용

- 마우스 수평 이동의 부호를 변경하여 오른쪽 이동 시 피사체도 오른쪽으로, 왼쪽 이동 시 왼쪽으로 움직인다. 수직 방향과 화면 주사율 기반 프레임 처리는 유지했다.
- 배경 분리의 움직임 입력은 `mouseEnabled`, `gyroEnabled`로 저장한다. 별도의 `liveEnabled`와 연결하지 않는다. 배경 분리 취소는 두 입력을 끄지만 Live 2D 상태는 유지한다. Live 2D 상태 저장 역시 배경 분리 레이어를 요구하지 않는다.
- Live 2D 탭에서 배경 분리의 레이어·강도·마우스 설정을 제거했다. Live 2D 구현은 담당 팀원이 이어갈 수 있도록 기존 상태 필드를 보존했다. 배경 분리만으로 Live 2D 기능 표시가 추가되지 않는다.
- 패널 순서는 분리 실행 → 레이어(전체·피사체·배경) → 움직임 강도 → 움직임 사용(마우스·자이로센서 아이콘 버튼) → 배경 분리 적용 취소 → 저장 및 내보내기다. 두 입력 버튼은 중복 선택할 수 있다.
- 강도는 숫자 입력과 슬라이더가 같은 0~100 정숫값을 사용한다. 입력 범위를 벗어나면 경계값으로 맞춘다. 움직임 사용 여부와 관계없이 분리 후 강도를 지정할 수 있다.
- 사진 하단의 움직임·주사율 문구와 강도 아래 설명을 제거했다. 저장 및 내보내기는 설정 패널 안에서 함께 스크롤하며 더 이상 고정된 별도 하단 영역이 아니다.
- 자이로는 버튼과 선택값 저장만 구현했다. 센서 권한 요청·이벤트 연결 코드는 주석 상태로 유지했고, 준비·적용 중 안내 문구를 넣지 않았다.

기존 JSON 편집 메타데이터를 사용하므로 DB 마이그레이션은 없다. 새 입력 필드를 보내지 않는 클라이언트는 기존에 저장된 두 선택값을 유지한다. 저장·스냅샷·재조회 경로에 선택값을 반영했으며, 기존 모바일/Windows 호환성을 위해 레이어 파일을 전달하는 `WallpaperMode.Live2D` 전송 형식은 유지한다. 이 전송 형식과 사용자가 선택하는 Live 2D 기능 상태는 별개다.
