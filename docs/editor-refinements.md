# 자르기 자동 저장과 레이어 미리보기

자르기 조작은 즉시 미리보기에 반영하고 `useCropAutosave`에서 기존 `saveImageEdit` API로 자동 저장한다. 저장·취소 버튼은 없다. 연속 변경은 200ms 동안 최신 값으로 합치고, 진행 중인 요청이 있으면 완료 후 최신 값만 순서대로 저장한다. 이미지별 대기 값을 유지하고 도구·이미지 이동·페이지 이탈 시 대기 중인 저장을 즉시 처리한다. 저장 요청은 `keepalive`를 사용한다.

기존에 저장된 편집에서 자르기 필드만 갱신하므로 아직 저장하지 않은 필터·제목 등은 함께 저장하지 않는다. 실패 시 현재 자르기를 유지하고 오류를 표시하며, 다시 조정하거나 전체 저장으로 재시도할 수 있다. 자동 저장 중에는 보관함 저장·공유·다운로드·기기 적용을 잠가 저장 요청 간 충돌을 막는다.

`cropPresentation`이 전체·피사체·배경의 중앙 미리보기와 레이어 썸네일에 같은 자르기 영역과 이미지 평면 위치를 제공한다. 수동 선택 Canvas는 잘린 화면 안에서도 전체 원본 좌표를 유지하므로 추가·제거 마스크의 내보내기 크기와 위치는 바뀌지 않는다. 썸네일은 잘린 이미지의 비율을 유지해 작은 프레임에 맞춘다.

움직임은 새 편집의 기본값 50을 사용한다. 버전 정보가 없는 이전 기본값 57은 50으로 정규화하며 그 외 저장 값은 보존한다. 새로 직접 지정한 값에는 버전을 기록하므로 57도 저장 후 유지된다. 브러쉬·지우개는 원본 이미지 좌표 기준 기본 150px, 최소 1px, 최대 500px이며 화면 배율에 따라 커서 크기를 조정한다.

백엔드·DB·GPU 워커를 변경하지 않고 기존 소유권과 공개 잠금, 최신 레이어 검증 및 편집 저장 API를 유지한다.

검증은 기존 자르기 비교·원본 좌표 검사에 최신 값 합치기·요청 순서·이미지별 대기·실패 복구 검사를 더한다. 브라우저에서 연속 비율 변경 직후 도구 이동과 새로고침을 해도 최신 자르기가 유지되고 별도 저장 버튼이 없는지 확인한다. 레이어와 썸네일 비율, 움직임 기본값, 브러쉬 기본값과 500px 상한도 유지한다.
