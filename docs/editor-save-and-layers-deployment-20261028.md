# 편집기 저장·레이어 수정 배포

2026-10-28 운영 주소: [Upscale Lab](http://13.124.225.10).

## 반영 내용

- 웹에서 새로 올린 이미지는 편집용 임시 프로젝트다. ‘보관함에 저장’ 또는 ‘업로드하고 저장’을 완료해야 내 이미지에 표시된다. 서버의 프로젝트 목록과 기존 이미지 목록 모두 임시 이미지를 제외한다.
- 저장 전 페이지 이동·뒤로 가기는 확인 창을 표시한다. 새로고침·탭 닫기는 브라우저 기본 이탈 경고를 사용한다. 이동을 취소하면 편집을 계속한다. 이동을 확인하면 임시 이미지를 폐기한다.
- 대기 중 폐기한 임시 작업은 GPU 실행을 건너뛴다. 실행 중 폐기한 작업은 입력을 유지하고 종료 후 임시 결과와 원본을 정리한다. 저장된 프로젝트에 늦게 도착한 임시 폐기 요청은 저장본을 삭제하지 않는다.
- 분리 결과의 레이어를 ‘전체’, ‘배경’, ‘피사체’로 표시한다. 실제 결과 썸네일을 누르면 중앙 미리보기가 해당 레이어로 전환되며, 피사체의 투명 영역은 체크무늬로 표시한다. ‘전체’는 배경과 피사체를 함께 보여 준다.
- 공유 링크 생성과 기기 적용은 보관함에 저장한 이미지에서 수행한다. ‘업로드하고 저장’은 저장을 완료한 뒤 공유한다.

기존 등록 이미지와 이전 모바일 클라이언트의 등록 방식은 유지한다. 새 임시 상태는 기존 `SavedEditJson` 메타데이터를 사용하며 DB 스키마·자격 증명·Runpod 워커 변경은 없다. 기존 저장 이미지의 GPU 처리 결과까지 별도 버전으로 되돌리는 기능은 이번 변경 범위에 포함하지 않는다.
