## 변경 사항

탐색의 이미지 클릭을 오른쪽 상세 패널로 변경했다. 미리보기, 작성자, 등록일, 해상도, 파일 형식, 다운로드 수와 전체 태그를 표시하며 화면 비율 항목은 두지 않는다. 내 이미지에 저장과 작업실에서 열기는 기존 가져오기 경로를 유지한다. 가져오기 중 다른 이미지를 선택하면 먼저 시작한 가져오기가 새 선택을 지우지 않는다.

상단 이미지 상세 켜기/끄기와 패널 닫기 버튼을 제공한다. 닫아도 현재 선택은 유지하고 표시 설정은 브라우저에 저장한다. 이미지를 선택하거나 공유 링크로 들어오면 상세 패널을 연다. 패널 안에서 Esc를 누르면 닫고 전환 버튼으로 포커스를 되돌린다. 선택한 카드는 인디고 테두리로 표시한다.

탐색과 내 이미지가 동일한 ImageCard를 사용하고 태그·픽셀 해상도·적용 기술 배지를 유지한다. 적용 기술은 공통 ImageFeatureBadges로 묶었다. 탐색 전용 카드 크기·본문 여백·배지 간격 예외를 제거하고 전체 탐색 영역의 너비로 내 이미지와 같은 카드 너비를 계산한다. 패널이 열리면 카드의 너비와 이미지 높이는 유지하면서 열 수가 줄어든다. 작은 화면에서는 상세 패널을 오른쪽에 겹쳐 표시하며 닫기 버튼을 유지한다.

새 이미지 작업실은 가용 화면 높이에 맞춰 페이지의 상하 스크롤을 제거했다. 최근 이미지 미리보기의 높이를 제한하고 높이가 낮은 창에서는 최근 이미지와 부가 안내를 접어 파일 선택 버튼을 유지한다.
