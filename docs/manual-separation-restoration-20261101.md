# 수동 분리·기기 관리·연결 앱 배포 복구

복구 기준은 병합 직전 main `336c140`이며 최신 화면 변경은 `f2a4814`다. `5127605`에서 빠진 기존 기능을 현재 main `4977129`의 Live 2D 캐릭터 기능과 함께 유지하도록 통합했다. 전체 브랜치를 되돌리지는 않았다.

## 복구한 기능

- 자동 분리 후 같은 작업실 Canvas에서 브러쉬·올가미로 추가 범위를 표시하고 지우개로 제거한다. 기본 크기 150px·최대 500px, 실행 취소·다시 실행·선택 초기화와 확대 시 이미지 이동을 복구했다.
- 최초 `피사체 자동 분리`와 이후 `피사체 다시 분리`를 같은 버튼으로 제공한다. 그리기만으로 서버 작업을 생성하지 않으며 처리 중·닫지 않은 올가미·수정 범위가 없는 재분리를 차단한다. 수정하지 않은 원본 알파는 유지한다.
- `/api/projects/{id}/subject-selection`, 호환 `/subject-mask`, 소유권·현재 레이어·공개 잠금·동시 처리·PNG 크기와 채널 검증을 복구했다. 서버가 원본 전경 알파와 추가·제거 범위를 결합하고 S3에는 이미지, PostgreSQL에는 마스크 object key를 저장한다.
- 저장된 마스크와 `.selection.png` 모드를 재시작 후 재사용하고, RunPod 요청·완료의 마스크 checksum과 모드를 대조한다. BiRefNet ROI 보정 및 LaMa 배경 복원과 프로젝트·계정 삭제/효과 초기화 시 마스크 정리를 복구했다.
- 자르기 즉시 미리보기·자동 저장·실패 표시·화면 전환 시 저장과 레이어 썸네일의 자르기를 복구했다. 움직임 기본값 50과 이전 기본값 57의 버전 구분도 복구했다.
- PC 모니터 이름 중앙 정렬, 왼쪽 주 화면 표시, 휴대폰 `연결안됨` 문구와 반응형 스타일·사이드바 동작을 복구했다.
- 연결 앱 다운로드는 기존 Windows EXE·Android APK **1.2.2**를 재사용한다. cloud 빌드는 설치 파일의 존재·버전·크기·SHA-256을 빌드 전후에 확인한다. 수동 웹 설치 도구는 설치 파일이 빠진 이전 형식의 배포 묶음에서 이전 릴리스의 다운로드 디렉터리를 보존하고, manifest와 EXE·APK가 없으면 전환하지 않는다.

## 유지한 Live 2D 기능

`CharacterLayers` 처리, 별도 See-through endpoint, 캐릭터 레이어 순서 API와 수동 조합, 파츠 목록·PNG 리깅 미리보기, rig 설정 저장을 유지했다. 배경 없는 캐릭터 레이어와 기존 배경·피사체 보정의 준비 상태를 구분한다. 토큰·결제 정책은 이번 복구에서 변경하지 않았다.

## 검증

- .NET 8: 백엔드 전체 **244개 통과**. 복구한 수동 보정 및 RunPod 마스크 검사, OpenAPI의 보정 API·캐릭터 레이어 순서 API, 기존 캐릭터 처리·리깅 검사를 포함한다.
- 웹: **101개 통과, 14개 생략**. 생략 항목은 공개 운영 주소가 필요한 검사다. TypeScript 검사와 cloud 프로덕션 빌드도 통과했다.
- GPU 워커: 모델·로컬 GPU 실행 없이 기존 계약·마스크 연산 검사 **14개 통과**.
- 실제 브라우저 Canvas: 3200×2000 원본, 801점 올가미의 독립 래스터 비교 차이 0픽셀, 추가·제거 채널·실행 취소·다시 실행·50회 브러쉬 검사 통과.
- 실제 Workspace → Studio → Canvas에서 수동 보정 패널과 자르기 자동 저장, 별도의 캐릭터 파츠·움직임 설정 활성화를 확인했다. 기기 관리 배치와 연결 앱 1.2.2 다운로드 링크를 확인했다.
- Android 기존 APK의 `apksigner verify --verbose --print-certs` 성공. 팀 인증서 SHA-256은 `d2e2dc332f34de8ea72a0d1b4aa2c428306ba7ae4529f26ed6dd504018572b93`다. EXE·APK 크기와 SHA-256은 기존 manifest와 일치한다.
- `deploy/install-web.sh` Bash 문법 검사 통과. 기존 사용자 미커밋 파일 13개는 별도 해시로 보존을 확인한다.

검증 자료와 복구 전 사본은 무시되는 `artifacts/manual-separation-restore-20261101/`에 보관한다. 실제 RunPod GPU 작업·실기기 배경화면 적용·운영 웹/API 배포는 이번 소스 복구 검증에 포함하지 않았다. 새 APK·EXE를 생성하지 않았으며 DB migration을 실행하거나 CI/CD를 추가하지 않았다.
