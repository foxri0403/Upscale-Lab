# Live 2D

## 사용

1. 새 이미지 등록에서 사진을 선택하고 필요한 자르기와 필터를 마친 뒤 **Live 2D**를 누릅니다. 기존 보관함 이미지도 상세 화면의 **Live 2D** 버튼으로 변환할 수 있습니다.
2. **미리보기 / 배경 / 인물·사물**로 분리 결과를 확인합니다. 기기를 기울이면 합성 미리보기의 전경만 움직입니다.
3. **Live 2D 사용**으로 선택한 뒤 **저장**을 누릅니다. **보관함에 저장** 또는 **저장 후 적용**을 선택합니다. 기존 보관함에서 변환한 경우 선택 즉시 해당 이미지에 레이어를 저장합니다.
4. 적용 시 Android의 라이브 배경화면 설정에서 최종 확인합니다. 적용 대상은 Android가 제공하는 선택지를 따르며 앱의 정적 배경화면 홈/잠금 선택과 별도로 처리합니다. 취소하면 기존 배경화면은 유지됩니다.

## 분리와 저장

- Android 7.0(API 24) 이상과 Google Play 서비스가 필요합니다. [ML Kit Subject Segmentation](https://developers.google.com/ml-kit/vision/subject-segmentation/android)의 전체 전경 마스크를 사용해 여러 인물·사물을 하나의 전경 PNG로 합칩니다. 최초 모델 다운로드 중이거나 오프라인이면 안내 후 다시 시도할 수 있습니다.
- 사진은 기기에서 처리하며 이 작업으로 서버에 업로드하거나 갤러리에 자동 공유하지 않습니다. 원본 등록/공유 동작은 기존 흐름을 사용합니다.
- EXIF 방향을 반영하고 긴 변을 최대 1600px로 제한합니다. 배경과 전경은 크기·좌표가 같은 PNG입니다. 전경은 마스크 기반 부드러운 알파를 보존합니다. 피사체나 배경을 찾지 못하면 결과를 저장하지 않습니다.
- 전경 자리는 주변의 관측된 배경색을 확산해 채웁니다. 가려진 실제 배경을 복원하는 생성형 모델은 아니므로 복잡한 무늬나 큰 피사체에는 흐릿한 영역이 생길 수 있습니다. 저장 전에 배경 탭으로 확인하세요.
- 임시 결과는 앱 캐시에만 두며 취소/저장 후 정리합니다. 저장된 두 레이어와 manifest는 앱의 영구 전용 저장소에 사용자 ID와 이미지 ID로 구분하고, 네이티브 저장/조회/삭제/적용 전에 기존 보관함 소유자를 확인합니다. 보관함의 원본에는 `mode=live2d`를 기록합니다.
- 적용할 때 별도 영구 복사본을 만들어 보관함 이미지 삭제와 로그아웃 후에도 배경화면이 유지됩니다. `manifest_path`는 Android 적용 확인 뒤에만 갱신하며 서비스가 이를 다시 읽습니다. 미리보기는 별도의 `preview_manifest_path`를 사용합니다.
- 앱 데이터 삭제/재설치로 전용 레이어 파일이 사라진 경우, 복원된 원본 상세 화면의 **다시 분리**로 레이어를 생성할 수 있습니다. 공유 게시물에는 원본 이미지만 공유되며 전용 레이어는 포함되지 않습니다.
- 자르기·필터 변경이나 업스케일 선택 시 이전 분리 결과를 해제합니다. 편집을 마친 뒤 다시 Live 2D를 선택하세요.

## 자이로 렌더링

`TiltSensor`는 자이로가 있는 기기에서 game rotation vector(대체: rotation vector)의 센서 융합 방향을 사용합니다. 보이는 시점의 자세를 기준으로 보정하고 화면 회전을 반영합니다. ±30도 범위로 제한하고 저역 통과 필터를 적용해 흔들림을 줄입니다. 전경 이동은 화면 너비/높이의 최대 3.5%, 양 레이어의 공통 확대는 8%입니다. 배경의 위치는 항상 고정됩니다. 미리보기와 실제 배경화면은 같은 센서와 이동 규칙을 사용합니다.

자이로/지원 방향 센서가 없으면 전경을 중앙에 고정합니다. 화면이 가려지거나 앱이 일시 중지되면 센서를 해제하고 배경화면 프레임 예약도 멈춥니다. 센서 변화가 있을 때만 프레임을 요청하며 적용한 배경화면은 manifest와 PNG만으로 재시작할 수 있습니다.

## 검증

```powershell
cd mobile
flutter analyze --no-pub
flutter test --no-pub
cd android
.\gradlew.bat :app:compileDebugKotlin :app:testDebugUnitTest --no-daemon
```

자동 테스트는 투명 전경 알파, 피사체 없는 배경 채움, 기울기 기준점/경계/각도 래핑, 모델 준비 실패와 재시도, 임시 파일 소유권 이전/취소 정리, Live 2D 버튼과 저장 모드, 전경만 움직이는 미리보기, 계정이 포함된 라이브 배경화면 연결을 확인합니다. 실제 ML 모델의 분리 품질과 기기 센서/Android 선택 화면은 실기기 확인이 필요합니다.

실기기에서는 사람·동물·사물/복수 피사체 사진, 첫 모델 다운로드와 오프라인 재시도, 세로/가로 회전, 적용/취소, 이미 같은 Live 2D 서비스가 적용된 상태에서 다른 사진 적용, 화면 껐다 켜기, 앱 종료와 기기 재부팅, 계정 전환/로그아웃, 보관함 원본 삭제 뒤 적용 유지, 앱 재설치 후 다시 분리를 확인하세요. APK를 배포할 경우 루트 `AGENTS.md`의 버전 및 서명 규칙을 별도로 따라야 합니다.
