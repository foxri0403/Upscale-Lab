# Live 2D

## 사용

1. 새 이미지 등록 또는 공유 중이 아닌 보관함 이미지의 **수정**에서 **Live 2D**를 누릅니다. 같은 편집 화면에서 분리 결과를 확인하며 현재 자르기 영역과 비율·필터를 유지합니다.
2. **미리보기 / 배경 / 인물·사물**로 분리 결과를 확인합니다. 기기를 기울이면 합성 미리보기의 전경만 움직입니다.
3. **Live 2D 적용**은 현재 자르기·필터를 반영해 Android 대상 선택 화면을 엽니다. 서비스가 이미 연결되어 있어도 다시 열리므로 홈에서 홈·잠금으로 변경할 수 있습니다. 선택 가능한 조합은 기기 Android가 제공하며 앱이 강제하지 않습니다. 완료 후 같은 편집 화면으로 돌아옵니다. 취소나 오류 시 기존 편집과 분리 결과를 유지합니다.
4. 돌아온 편집 화면에서 **사진 정보 / 자르기 / 필터**를 계속 이용할 수 있습니다. **저장**은 추가 팝업 없이 앱 전용 보관함에만 저장합니다. **배경화면 등록**은 최신 편집 결과와 레이어를 저장한 뒤 Android에서 연결한 화면에 바로 반영합니다. Live 2D에는 홈·잠금 선택창을 다시 띄우지 않습니다. 저장 또는 등록 후에는 보관함으로 돌아갑니다. 저장한 Live 2D는 편집용 레이어를 복제해 불러오므로 다시 분리할 필요가 없습니다.
5. 저장한 Live 2D도 보관함 우측 상단 **배경화면 설정**에서 즉시 등록합니다. 대상을 바꾸려면 점 세 개 메뉴의 **Live 2D 적용 화면 변경**을 누릅니다. 공유 중인 이미지도 보관함 내용을 수정하지 않고 적용 대상만 변경할 수 있습니다. 앱 재실행 후에도 Android의 실제 활성 대상을 조회하며 영구 권한 허용 값을 따로 저장하지 않습니다. 외부에서 라이브 배경화면을 해제하면 **Live 2D 적용**으로 재연결합니다. 일반 등록 실패에서 시스템 화면을 자동 실행하지 않으며, 정적 이미지로 대체하지 않습니다.

Android의 서비스 최초 연결 및 대상 변경은 일반 앱이 확인 화면 없이 수행할 수 없습니다. [공식 확인 인텐트](https://developer.android.com/reference/android/app/WallpaperManager#ACTION_CHANGE_LIVE_WALLPAPER)는 명시적인 **Live 2D 적용**에서 사용하며, 이후 등록은 연결된 대상을 그대로 갱신합니다. 시스템 설정에서 연결을 해제하거나 다른 대상으로 다시 연결하면 상태가 바뀌므로 재연결이 필요할 수 있습니다.

설정의 **배경화면 제거**에서는 홈·잠금을 각각 체크하거나 함께 선택할 수 있습니다. 선택이 없으면 **삭제**가 비활성화되고 **취소**는 아무것도 변경하지 않습니다. 잠금만 제거하면 Android에서 홈 배경화면을 잠금에도 표시할 수 있으며 보관함 이미지는 삭제하지 않습니다.

## 분리와 저장

- Android 7.0(API 24) 이상과 Google Play 서비스가 필요합니다. [ML Kit Subject Segmentation](https://developers.google.com/ml-kit/vision/subject-segmentation/android)의 전체 전경 마스크를 사용해 여러 인물·사물을 하나의 전경 PNG로 합칩니다. 최초 모델 다운로드 중이거나 오프라인이면 안내 후 다시 시도할 수 있습니다.
- 사진은 기기에서 처리하며 이 작업으로 서버에 업로드하거나 갤러리에 자동 공유하지 않습니다. 원본 등록/공유 동작은 기존 흐름을 사용합니다.
- EXIF 방향을 반영하고 긴 변을 최대 1600px로 제한합니다. 배경과 전경은 크기·좌표가 같은 PNG입니다. 전경은 마스크 기반 부드러운 알파를 보존합니다. 피사체나 배경을 찾지 못하면 결과를 저장하지 않습니다.
- 전경 자리는 주변의 관측된 배경색을 확산해 채웁니다. 가려진 실제 배경을 복원하는 생성형 모델은 아니므로 복잡한 무늬나 큰 피사체에는 흐릿한 영역이 생길 수 있습니다. 저장 전에 배경 탭으로 확인하세요.
- 임시 결과는 앱 캐시에만 두며 취소/저장 후 정리합니다. 저장된 두 레이어와 manifest는 앱의 영구 전용 저장소에 사용자 ID와 이미지 ID로 구분하고, 네이티브 저장/조회/삭제/적용 전에 기존 보관함 소유자를 확인합니다. 보관함의 원본에는 `mode=live2d`를 기록합니다.
- 원본과 메타데이터도 [앱 전용 이미지 저장소](private-image-storage.md)에 저장하며 기기 갤러리에 새 복사본을 생성하지 않습니다. 기존 앨범 이전 시 이미지 ID와 Live 2D 모드를 유지합니다.
- 적용할 때 별도 영구 복사본을 만들어 보관함 이미지 삭제와 로그아웃 후에도 배경화면이 유지됩니다. 최초 활성화는 `preview_manifest_path`와 Android 16의 `Engine.onApplyWallpaper()`/`WallpaperDescription`을 사용합니다. 이미 활성화된 대상의 직접 적용은 `direct_manifest_path` 갱신을 서비스에 알립니다. 영구 복사본의 단조 증가 `selectionRevision`으로 이전 Android 설명보다 새로운 직접 적용을 선택하고, 이후의 명시적 Android 선택은 다시 우선합니다. 일반 이미지 적용 브리지도 Live 2D 모드인 이미지를 정적으로 적용하지 않습니다.
- 실제 엔진은 표면 생성/복원과 다시 보이는 시점마다 적용된 manifest를 확인하고 센서와 프레임을 다시 연결합니다. 같은 manifest의 중복 설정 알림과 크기 변경에서는 비트맵을 다시 디코딩하지 않습니다. 중복 가시성/크기 변경 알림으로 자세 기준점이 계속 초기화되지 않도록 센서 등록은 한 번만 유지합니다. 미리보기 종료는 실제 배경화면 엔진의 센서에 영향을 주지 않습니다.
- 엔진은 디코딩한 비트맵의 긴 변을 1600px, 저메모리 기기에서는 1024px 이내로 제한하며 센서 프레임 간격은 33ms입니다. 메모리 부족과 캔버스 획득·그리기·반환 시 예외를 처리합니다. Android 9 SM-A530N에서 보고한 재부팅은 직접 진단 로그가 없어 원인이 확정되지 않았습니다. 이 보강을 재부팅 해결 확인으로 간주하지 않습니다.
- 공유 중이 아닌 이미지의 편집기에서 **Live 2D → 다시 분리**로 레이어를 다시 생성할 수 있습니다. 앱 데이터 삭제/제거 시 내부 원본과 레이어가 함께 제거됩니다. 공유 게시물에는 원본 이미지만 공유되며 전용 레이어는 포함되지 않습니다.
- 편집 중에는 원본 전체를 분리한 레이어를 보존합니다. 비율·자르기·필터 변경과 도구 전환은 Live 2D를 해제하지 않으며, 다시 Live 2D를 누르면 기존 분리 결과를 사용합니다. 자르기 도구에서는 원본에 가이드를 표시하고 다른 도구에서는 현재 자르기와 필터를 반영한 자이로 미리보기를 표시합니다.
- 저장 시 원본 등록 이미지와 두 레이어에 같은 정규화 자르기 영역과 필터를 적용합니다. 전경의 투명도를 유지한 PNG를 새 임시 레이어 묶음으로 만든 뒤 저장에 전달하며, 실패하면 기존 분리 결과로 재시도할 수 있습니다. 편집 초기화나 별도 변환 방식인 업스케일 선택은 Live 2D를 해제합니다.

## 자이로 렌더링

`TiltSensor`는 자이로가 있는 기기에서 game rotation vector(대체: rotation vector)의 센서 융합 방향을 사용합니다. 보이는 시점의 자세를 기준으로 보정하고 화면 회전을 반영합니다. ±30도 범위로 제한하고 저역 통과 필터를 적용해 흔들림을 줄입니다. 전경 이동은 화면 너비/높이의 최대 3.5%, 양 레이어의 공통 확대는 8%입니다. 배경의 위치는 항상 고정됩니다. 미리보기와 실제 배경화면은 같은 센서와 이동 규칙을 사용합니다.

자이로/지원 방향 센서가 없으면 전경을 중앙에 고정합니다. 화면이 가려지거나 앱이 일시 중지되면 센서를 해제하고 배경화면 프레임 예약도 멈춥니다. 센서 변화가 있을 때만 프레임을 요청하며 적용한 배경화면은 manifest와 PNG만으로 재시작할 수 있습니다.

## 검증

```powershell
cd mobile
flutter analyze --no-pub
flutter test --no-pub
cd android
.\gradlew.bat :app:compileDebugKotlin :app:testDebugUnitTest --no-daemon
```

자동 테스트는 자동/가로/세로의 단독 선택, Live 2D 전환 전후 비율 유지, 전환 후 자르기·필터와 최종 레이어 저장, 저장 실패 후 재시도, 모든 필터의 투명 전경 알파, 피사체 없는 배경 채움, 기울기 기준점/경계/각도 래핑, 모델 준비 실패와 재시도, 임시 파일 소유권 이전/취소 정리, Live 2D 버튼과 저장 모드, 전경만 움직이는 미리보기, 계정이 포함된 라이브 배경화면 연결을 확인합니다. 실제 ML 모델의 분리 품질과 기기 센서/Android 선택 화면은 실기기 확인이 필요합니다.

실기기에서는 사람·동물·사물/복수 피사체 사진, 첫 모델 다운로드와 오프라인 재시도, 세로/가로 회전, 적용/취소, 이미 같은 Live 2D 서비스가 적용된 상태에서 다른 사진 적용, 화면 껐다 켜기, 앱 종료와 기기 재부팅, 계정 전환/로그아웃, 보관함 원본 삭제 뒤 적용 유지, 앱 재설치 후 다시 분리를 확인하세요. APK를 배포할 경우 루트 `AGENTS.md`의 버전 및 서명 규칙을 별도로 따라야 합니다.
