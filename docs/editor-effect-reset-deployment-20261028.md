# 원본 복구·기능별 취소·마우스 움직임 배포

2026-10-28 운영 주소: [Upscale Lab](http://13.124.225.10).

## 동작

- 편집 초기화는 서버의 업스케일 결과·분리 레이어·처리 이력을 해제하고 필터·자르기·배율·움직임 설정을 기본값으로 돌린다. 업로드한 원본 이미지와 이름·태그 메타데이터는 유지한다.
- 업스케일 설정에 ‘업스케일 적용 취소’, 배경 분리 설정에 ‘배경 분리 적용 취소’를 추가했다.
- 업스케일만 취소하면 분리 레이어를 원본 해상도로 리샘플링하며 투명도와 움직임 비율을 유지한다. 배경 분리만 취소하면 업스케일 결과와 다른 편집 설정을 유지하고 레이어·움직임을 해제한다.
- 초기화·적용 취소는 명시적인 서버 작업이다. 임시 업로드는 이 작업으로 보관함에 등록되지 않는다. 처리 중에는 초기화·적용 취소 버튼을 비활성화하고 API도 충돌로 거부한다.
- 원본과 이미 만들어진 기기용 배경화면 스냅샷은 보존한다. 소유자 확인과 공개 공유 중 편집 잠금을 적용한다. 새 리샘플 파일 업로드와 DB 반영이 끝난 뒤 해제된 결과 파일을 정리한다.
- 배경 분리와 Live 2D 설정에서 같은 움직임 체크박스와 `Edit.Strength`를 사용한다. 배경 분리 화면에서도 마우스로 피사체가 움직이며, 끄면 프레임 요청을 중단하고 위치를 복원한다. 프레임은 기존 `requestAnimationFrame`과 경과 시간 기반 보간을 사용한다.
- 사용자가 HTTPS 도메인 없이 진행하도록 요청하여 웹 자이로의 권한·이벤트 연결 코드를 `web/src/use-parallax.ts`에서 주석 처리했다. 센서 버튼과 안내는 활성 UI에서 제외했다. 향후 복구 시 센서와 마우스는 동일한 강도·프레임 경로를 사용한다. Android 네이티브 센서는 변경하지 않았다.

## API

인증된 `POST /api/projects/{projectId}/effects/reset`에 `{"feature":"All"}`, `Upscale`, `Layers` 중 하나를 전달한다. 응답은 갱신된 프로젝트 상세다. 컨트롤러는 프로젝트 서비스에 위임한다. DB 스키마와 공급자 설정은 변경하지 않았다.

백엔드 테스트 176개가 통과했다. 초기화·개별 취소·레거시 통합 작업 분리·소유자 및 공유 잠금·처리 중 거부·업로드 실패 시 결과 보존·임시 업로드 유지 검증을 포함한다. 웹 50개도 통과했으며 이 중 14개는 실제 운영 연결 점검이다.

운영 API는 별도 테스트 계정과 작은 PNG를 사용해 원본 복구, 업스케일 취소 후 실제 레이어의 원본 크기·알파, 분리 취소 후 업스케일 유지, 임시 목록 숨김·명시 저장·폐기를 검증했다. 처리 결과는 검증 계정에만 미리 준비했으며 GPU 추론을 제출하지 않았다. 계정과 테스트 파일을 정리했고 실행 도구는 운영 API 디렉터리에서 제거했다.

실제 운영 JavaScript를 Edge에서 실행하고 API 응답을 모의 처리해 마우스 켜기·끄기·강도, 두 설정 탭의 공통 강도, 세 레이어 미리보기, 각 적용 취소와 전체 초기화, 이탈 경고·명시 저장을 확인했다. 브라우저 오류는 없었다.

API·nginx는 정상 동작한다. 배포 후 루트 디스크는 99% 사용 중이며 여유 공간은 약 220MB다. 기존 릴리스 및 다른 작업의 파일은 삭제하지 않았다. 이미지 처리용 임시 공간을 확보하기 위한 별도 정리가 필요하다. APK·Windows 설치 파일, 자격 증명, Runpod 워커 및 자동 배포 설정은 변경하지 않았다.
