# 현재 웹서비스 동작

이 문서는 전환 과정에 분산된 기능·복구 메모에서 현재 유지하는 계약을 모았다. 화면과 비즈니스 로직은 web/와 backend/에 있고, 연결 앱은 기기 인증·상태 보고·OS 배경화면 적용을 담당한다. 과거 날짜별 배포 기록의 서버 경로와 당시 테스트 수는 현재 상태의 근거로 사용하지 않는다.

## 보관함·공유·탐색

원본과 처리 결과는 S3, 소유권과 메타데이터는 PostgreSQL에 저장한다. 사용자 소유 리소스는 인증된 UserId로 검증한다. 공개 중인 원본 프로젝트는 편집을 잠그며 관련 공개 버전을 모두 공유 해제한 뒤 수정할 수 있다. 이름·태그·공개 상태는 서버 응답을 기준으로 갱신한다.

탐색의 본인 게시물에서는 카드 설정으로 이미지 이름과 상위·하위 태그를 수정하거나 업로드를 취소할 수 있다. 이름과 태그는 원본 픽셀 및 편집 설정과 별도로 바뀐다.

프로젝트와 해당 기기용 불변 결과물은 내 이미지 카드 하나로 묶지만 실제 결과물은 별도로 유지한다. 원본이 없는 가져온 결과물은 독립 카드로 표시한다. 기존 자산을 재사용하고 픽셀 변환 때문에 이번 작업이 새로 올린 임시 프로젝트만 결과물 복사 후 정리한다.

공유 결과물은 인증된 가져오기 API로 개인 보관함에 복사한다. 과거 갤러리 게시물도 POST /api/gallery/{id}/import에서 서버가 S3 객체를 복사하며 브라우저에서 서명 URL을 읽어 재업로드하지 않는다. 소유자·공개 상태를 확인하고 원본 비율·메타데이터·레이어를 보존한다. 공유 해제로 이미 가져온 사본을 회수하지 않는다.

다른 사용자의 게시물을 저장하면 읽기 전용으로 표시한다. 예전 배경화면 사본도 소유한 원본 프로젝트나 직접 생성 이력을 확인할 수 없으면 읽기 전용으로 연다. 배경화면 적용 미리보기의 화면 비율·확대·위치는 기기용 결과물에만 저장한다.

작업실 태그 설정에서 PC·모바일·태블릿을 상위 태그로 복수 선택한다. 기존 장르 분류는 하위 태그로 유지한다. 탐색의 추천 영역은 좋아요를 기준으로 정렬하고 좋아요가 없는 경우 무작위로 고른다. 아래 목록은 최신순을 기본으로 하며 상위·하위 태그, 이미지 이름과 정렬 기준을 함께 적용한다.

다른 사용자가 공개한 이미지에 계정당 한 번 좋아요를 누를 수 있으며 다시 누르면 취소된다. 다운로드 수는 다른 사용자의 보관함에 성공적으로 복사된 횟수다. 사본 생성과 카운트 증가는 같은 DB 트랜잭션에서 처리한다. 썸네일, 미리보기, 다운로드 URL 발급 및 구형 다운로드 완료 요청은 현재 집계값을 바꾸지 않는다. 이전 파일 다운로드 이력은 별도 컬럼에 보존한다.

결과물 삭제는 숨김·공유 해제 처리다. 적용 중인 기기의 재시작 복구에 필요한 파일을 즉시 제거하지 않는다. 프로젝트·결과물·공유 사본·OS 캐시의 수명은 각각 구분한다.

## 작업실·저장·미리보기

업로드, 이미지 정보, 자르기, 필터, 업스케일, 배경 분리와 Live 2D는 기존 작업실을 사용한다. FHD/QHD/4K는 실제 목표 긴 변 해상도이며 원본 비율을 유지한다. 완료한 작업만 결과를 교체하고 실패하면 마지막 성공 결과를 보존한다. 원본 복구와 기능별 초기화는 해당 효과·저장 상태에 맞는 API를 사용한다.

자르기는 즉시 미리보기에 반영하고 useCropAutosave가 기존 편집 저장 API로 자동 저장한다. 200ms 동안 연속 변경을 합치고 진행 중 요청 뒤 최신 값만 순서대로 보낸다. 도구·이미지 이동과 페이지 이탈에서 대기 값을 처리하며 요청은 keepalive를 사용한다. 저장된 편집 중 자르기 필드만 바꾸므로 미저장 제목·필터까지 함께 저장하지 않는다. 오류 시 조작 값을 보존하고 재조정/전체 저장으로 재시도한다. 자동 저장 중 보관함 저장·공유·다운로드·기기 적용은 잠근다.

전체·피사체·배경 미리보기와 레이어 썸네일은 같은 자르기 영역과 이미지 평면을 사용한다. 선택 마스크는 화면 확대·자르기와 별개로 원본 좌표와 해상도를 유지한다. 수동 선택 중 Move, Space+드래그 또는 가운데 버튼으로 이동한다. 일반 미리보기는 직접 드래그로 이동한다. 배율은 25~200%이고 화면 맞춤은 별도 동작이다.

새 편집의 움직임 기본값은 50이다. 버전 정보가 없는 이전 기본값 57은 50으로 정규화하고 직접 저장한 값과 다른 기존 값은 보존한다. 브러쉬·지우개는 원본 좌표 150px, 범위 1~500px이다. [피사체 선택 계약](subject-selection.md)과 [Live 2D·레이어](live-2d.md)를 함께 참고한다.

## 기기·연결 앱

작업실, 탐색, 기기 관리에서 적용 전에 대상 화면 해상도에 맞춘 미리보기를 열 수 있다. 화면 채우기와 이미지 전체 표시 중에서 선택하고 확대와 위치를 조정한다. 서버는 확정한 배치를 적용용 결과물에 저장하며 Live 2D는 레이어와 움직임 설정을 유지한다.

웹의 기기 관리는 실제 물리 화면 수·해상도·주사율·OS·연결 상태를 표시한다. 제조사·모델·CPU 구조는 수집하거나 표시하지 않는다. Android Home/Lock은 한 물리 화면의 적용 대상이며 외부 화면은 정보 조회 전용이다. 최근 통신은 전원 켜짐을 확정하는 값이 아니다.

변경 알림으로 기기 정보만 다시 읽고 동시 요청을 합쳐 이전 응답이 최신 상태를 덮지 않게 한다. 창 복귀·재연결도 갱신한다. 적용 명령은 DB에 보존하며 같은 대상의 최신 sequence를 확인한다. 기기가 OS 적용을 확인하고 Applied를 보고한 뒤 실제 적용 상태를 변경한다. Android 첫 Live 2D 활성화는 NeedsUserAction 상태로 시스템 승인을 기다릴 수 있다.

배경화면 삭제는 선택 화면의 OS 초기화 API를 호출하고 확인한 뒤 보고한다. 다른 화면과 개인 보관함은 보존한다. 연결 해제·계정 로그아웃은 새 명령과 Live 2D 움직임을 중지하며 이미 적용된 정적 배경화면은 유지한다. [기기 API](agent-api.md), [연결 앱](companion-apps.md)을 따른다.

## 로그인·결제·운영

웹은 기본 sessionStorage를 쓰며 자동 로그인 선택 시 localStorage를 쓴다. 토큰 갱신은 동시 요청을 합치고 서버 세션 폐기·만료를 따른다. [인증 API](auth-api.md)에 세션과 인증 대기 정보 만료 정책을 모았다. 결제·구독·토큰 정산과 복구 worker는 현재 API에서 사용하므로 유지한다.

작은 화면은 접이식 메뉴와 세로 작업실을 사용하고 편집 도구·설정·저장 영역에 스크롤로 접근한다. 자이로 권한에는 HTTPS 보안 컨텍스트와 지원 브라우저가 필요하다. 설치 파일은 /downloads/manifest.json의 버전·크기·SHA-256으로 검증한다.

운영 배포는 [배포 가이드](deployment.md)의 수동 절차를 따른다. 로컬 빌드·모의 서버 테스트는 실제 AWS 권한, 원격 모델 품질, 결제 승인, OS 적용을 대신하지 않는다. 이번 저장소 정리에서는 운영 서버·DB·클라우드 자원·배포를 변경하지 않는다.
