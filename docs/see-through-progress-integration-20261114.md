# 실사 See-through/진행률 UI 통합 안내 (2026-11-14)

## 적용 범위

기준: `Upscale-Lab-gusrb03-gallery-studio-refinements (2).zip` (최신 제공 ZIP, 이전 (1) 버전과 파일별 내용 일치).

- 업스케일·배경 분리·Live2D의 진행률 표시를 `숫자 % + 진행 막대 + 현재 작업 단계`로 통일. 백엔드가 제공하는 **단계별 진행률**이며 AI 내부 실제 완료율은 아님.
- 기존 See-through와 `CharacterLayers`/RunPod 경로를 그대로 사용하며 실사 분리 결과 처리만 보완. 모델 변경, 별도 미세조정, 학습 데이터 추가는 없음.
- See-through 결과에 배경 파츠가 포함돼도 얼굴/머리 파츠가 있으면 Live2D 리깅으로 인식. 배경+일반 피사체 2레이어에는 캐릭터 리깅을 활성화하지 않도록 내보내기 판별도 보완.
- 기존 수동 레이어 조합 화면과 역할 지정 기능을 유지하고, 배경 레이어는 움직임 역할을 변경하지 못하게 함.
- 팀원의 **업스케일 + 배경 분리/Live2D 중 하나만 허용**, `(재수정)` 표시, 기존 서비스 API, 토큰/로그인 로직 변경하지 않음.

## 통합 지침

1. 이 ZIP은 **전체 프로젝트 소스**이며 팀원 최신 ZIP을 바탕으로 수정. 기존 Git 브랜치 위에 통째로 덮어쓰기 전에 별도 브랜치에서 비교할 것.
2. `web` 디렉터리에서 `pnpm install --frozen-lockfile` 후 `pnpm test`, `pnpm run build`로 검증.
3. 이미 운영 중인 AWS/RunPod에 자동 배포하지 않음. 팀원의 신규 커밋이 있으면 충돌 검사 후 통합.
4. 실사 사진은 기존 See-through 결과에 기반한 **제한적 2.5D 모션**. 자연스러운 3D 얼굴 시점 생성은 제공하지 않음.
5. 수동 레이어 조합에서 역할을 수정한 경우 **작업실 전체 저장**까지 정상 완료되는지 확인.
6. 내일 로컬 GPU로 전환할 때에는 API/worker 연동 방식이 바뀌므로 별도 작업 필요. 이 수정본은 GPU 전환을 구현하지 않음.

## 검증 범위

- 기존 팀 소스의 수동 조합/재수정/동시 제한 코드는 보존됨.
- 실제 배경화면, Windows 연결 앱, RunPod 실사 추론, 운영 배포는 별도 검증 필요.

## 2026-11-15 최신 ZIP 병합 점검

- `(2).zip`의 전체 643개 소스 파일은 `(1).zip`과 동일한 내용이어서 기존 통합 패치가 충돌 없이 적용됨.
- `web/src/wallpaper-export-policy.ts`에 배경 PNG가 포함된 See-through 레이어의 리깅 판별을 보완. 일반적인 `Background + Body` 배경 분리만으로 캐릭터 리깅을 켜지는 않음.
- 해당 예외 처리에 대한 회귀 테스트 2건을 추가.
- Node.js 22.16의 TypeScript 기본 기능이 비활성화되어, 개발 환경의 TypeScript 5.8 변환 로더를 임시로 사용해 웹 테스트 162개 실행: **147개 통과, 15개 건너뜀, 실패 0개**.
- 전체 `pnpm run build` / .NET 빌드는 이 환경에서 미실행. 메인 브랜치 병합·서버 배포 전 별도 실행 필요.
- GPU 실행 방식·API 계약·기존 그룹/기울기 슬라이더·기기 적용 기능은 변경하지 않음.
