# 보관함 이미지 수정

공유 중이 아닌 이미지의 **수정**은 등록에 쓰는 `ImageFeaturePage`를 엽니다. 기존 이름·태그·비율을 불러오며 사진 정보, 자르기, 필터, 업스케일, Live 2D를 같은 도구로 사용합니다. 저장한 Live 2D는 앱 캐시에 복제한 레이어로 편집하고 원래 보관함 레이어는 저장할 때까지 유지합니다.

- 자르기·필터는 원본 등록 이미지와 두 레이어에 같은 좌표와 효과를 적용합니다.
- 업스케일은 등록과 같은 서버 작업을 실행하고 실제 결과 해상도가 선택 배율과 일치하는지 검사합니다. 성공한 결과로 기존 이미지를 교체하며 새 보관함 항목을 추가하지 않습니다.
- 저장 시 이미지 ID와 생성 시각을 유지하고 수정 시각은 UTC로 기록합니다. 새 파일명을 사용해 이전 썸네일 캐시가 표시되지 않게 합니다.
- 사진, 메타데이터, Live 2D 레이어를 임시 폴더에 준비하고 검증한 뒤 기존 폴더와 교체합니다. 교체 중 중단되면 백업을 복구하며, 준비 실패 시 기존 파일을 유지합니다. 저장 실패 후 편집기는 열린 채로 재시도할 수 있습니다.
- 기존 `files/live_2d/<owner>/<image>/` 레이어도 불러올 수 있습니다. 새 레이어는 해당 이미지의 `files/image_library/<owner>/<image>/live2d/`에 저장합니다.
- 공유 중인 이미지에서는 보관함과 상세 화면의 수정 메뉴 및 새 Live 2D 변환을 숨깁니다. 저장 시 네이티브 계층에서 현재 공유 상태와 사용자 소유권을 다시 확인합니다. 공유를 취소하면 다시 수정할 수 있습니다. 이미 공유한 게시물은 수정 화면에서 갱신하지 않습니다.

**Live 2D 적용**은 같은 편집 화면에서 레이어 효과를 선택합니다. 화면을 이동하거나 배경화면을 변경하지 않으며, 이후에도 사진 정보·비율·자르기·필터를 사용할 수 있습니다. 편집기를 닫으면 저장하지 않은 변경은 반영되지 않습니다.

하단 동작은 **저장 / 배경화면 등록**으로 나뉩니다. **저장**은 추가 팝업 없이 앱 전용 보관함에만 저장합니다. **배경화면 등록**은 홈·잠금 체크박스를 표시하며 두 화면을 함께 선택할 수 있습니다. 선택이 없으면 **등록**이 비활성화되고, **취소**하면 편집 화면을 유지합니다. 등록을 확인하면 편집한 이미지와 레이어를 먼저 저장한 다음 선택한 화면에 적용합니다. 저장 또는 등록을 마치면 보관함으로 돌아갑니다. 배경화면 적용이 실패하거나 Android 확인을 취소하더라도 저장한 이미지는 유지됩니다.

보관함 이미지를 누르면 확대할 수 있는 미리보기를 표시합니다. 하단 적용 패널은 없으며, 우측 상단 **배경화면 설정**에서 홈·잠금 또는 둘 다를 선택해 등록할 수 있습니다. Live 2D 최초 연결과 대상 변경에 필요한 Android 확인은 실제 등록 단계에서만 요청합니다.
