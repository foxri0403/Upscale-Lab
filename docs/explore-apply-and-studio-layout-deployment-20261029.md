## 변경

다른 사용자의 탐색 이미지에서 작업실 열기를 ‘연결된 기기에 적용’으로 변경했다. 기기와 화면을 선택하고 확인한 뒤 내 계정의 이미지로 가져와 기존 기기 명령 API에 요청한다. 선택 취소나 대상 없음에서는 가져오기·명령을 생성하지 않는다. 온라인이며 적용을 지원하는 연결 화면만 제공하고 Windows 모니터와 Android 홈·잠금 화면을 구분한다.

웹 공유 결과물은 기존 import API가 만든 내 계정의 불변 결과물을 그대로 적용해 레이어와 움직임 manifest를 유지한다. 기존 모바일 게시물은 읽기 전용 원본 URL을 받아 내 계정 프로젝트로 가져온 뒤 기존 결과물 생성 경로를 사용한다. 다른 작성자의 프로젝트 ID를 편집 권한으로 사용하지 않는다. 전송 실패 후 재시도에서 같은 가져오기 결과를 재사용한다. 명령 접수 후 상태 조회만 실패한 경우에는 접수 사실을 유지해 같은 요청을 다시 전송하도록 유도하지 않는다. 실제 완료는 연결 앱 보고 후 확인한다.

내가 공유한 이미지는 ‘내 이미지에 저장’을 숨긴다. 작업실 열기는 공개 버전·모바일 게시물 ID를 인증된 내 보관함의 원본과 연결해 기존 원본을 연다. 이름이나 URL이 같다는 이유만으로 소유권을 판단하지 않는다.

작업실의 이미지 이름·편집 초기화·정보 표시줄은 중앙 편집 영역까지만 차지하게 하고 오른쪽 이미지 설정 패널은 첫 행부터 전체 높이를 사용하게 했다. 도구 막대와 캔버스는 다음 행에 배치하며 여섯 편집 도구에 같은 규칙을 적용한다. 설정 패널은 내용이 넘칠 때만 스크롤하고 루트와 내부 스크롤바 공간을 안정적으로 유지한다.
