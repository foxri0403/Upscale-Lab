# HTTPS 자이로 연결 및 버튼 글자 크기 수정

2026-10-28 운영 웹: [Upscale Lab](https://d3bjir1z2hduu0.cloudfront.net/).

## 동작

- 기존 자이로센서 버튼에서 브라우저의 센서 권한을 요청한다. 권한을 거부하면 센서를 활성화하지 않고 기존 오류 알림을 사용한다. 별도의 준비·진행 안내 문구를 추가하지 않았다.
- `DeviceOrientationEvent.requestPermission`이 있는 브라우저에서는 버튼의 사용자 동작 안에서 해당 메서드를 호출한다. 메서드가 없는 브라우저는 HTTPS와 지원 여부·센서 정책을 확인한 뒤 이벤트를 구독한다. [W3C Device Orientation and Motion 규격](https://www.w3.org/TR/orientation-event/)을 참고했다.
- 첫 유효한 기울기를 중립 위치로 보정하며 가로·세로 화면 회전을 반영한다. 강도 변경은 보정 기준을 초기화하지 않고 같은 움직임에 바로 적용된다.
- 마우스와 자이로를 함께 선택하면 입력을 합산하고 허용 범위 안으로 제한한다. 둘 다 같은 `Edit.Strength`를 사용한다. 마우스가 이미지에서 벗어나면 마우스 입력만 중립으로 돌아간다.
- 센서를 끄거나 다른 도구로 이동하거나 페이지가 숨겨지면 이벤트·프레임을 정리한다. 표시 상태로 돌아오면 다시 중립 보정한다. 저장된 자이로 설정이 있어도 별도 권한 API를 가진 새 문서에서는 사용자가 버튼으로 권한을 허용한 후 실행한다.
- 공유·기기 적용용 스냅샷의 `MotionEnabled`는 마우스 또는 자이로 중 하나라도 선택되면 켜진다. 별도 Live 2D 설정은 변경하지 않는다.
- 배경 분리 적용 취소 버튼의 `font-size`를 상단 분리 시작 버튼과 같은 값으로 맞췄다.

## 검증과 범위

- HTTPS 운영 주소 대상 웹 테스트 52개 통과. 프레임 보간·화면 회전·동시 입력 제한 테스트와 운영 연결 점검 14개를 포함한다.
- 운영 JavaScript를 실제 Edge에서 실행하고 iOS 방식 권한 API 및 Android 방식 센서 경로를 각각 모의하여 검증했다. 권한 허용·거부와 사용자 동작 안에서의 요청, 기울기, 공통 강도, 가로 모드 보정, 마우스와 동시 선택, 숨김/재표시, 센서 끄기, 저장 후 재조회가 통과했다. API 응답과 센서 값은 자동화에서 모의했다. 두 경우 모두 브라우저 오류 0건이다.
- 두 버튼의 계산된 `font-size`가 일치하는 것을 배포된 HTTPS 화면에서 확인했다.
- 별도의 운영 검증 계정으로 실제 CloudFront HTTPS 로그인·업로드·명시 저장·임시 폐기·소유권 보호를 확인했다. 계정과 이미지를 정리했으며 GPU 추론은 제출하지 않았다.
- 물리적인 iPhone/Android 센서를 직접 사용한 실기기 시험은 수행하지 않았다. 브라우저의 센서 지원과 사용자 권한이 필요하다.

운영 디스크 여유는 약 180MiB로 계속 부족하다. 이번 배포는 작은 웹 변경만 반영했고 다른 작업의 데이터나 복구 릴리스를 삭제하지 않았다.
