# 피사체 분리 로컬 실험실

로컬 웹에서 실제 자동 분리와 브러시·올가미 수정 후 재분리를 테스트한다. 운영 웹/API를 배포하거나 운영 PostgreSQL에 접속하지 않는다.

## 실행

저장소 루트의 PowerShell에서 실행한다. 웹 의존성 설치와 .NET 8 SDK, SSH 연결 권한이 필요하다.

```powershell
./web/scripts/separation-lab.ps1 -RemoteHost ubuntu@YOUR_SSH_HOST -RemoteSettingsFile /etc/upscale-lab/upscale-lab.env
```

출력된 `http://127.0.0.1:5173/lab/separation`을 연다. 포트 충돌 시 `-WebPort 5174 -ApiPort 5092`처럼 다른 포트를 지정한다. 프로그램은 기존 프로세스를 종료하지 않는다.

1. 이미지를 선택하거나 여우 샘플을 연다.
2. 위의 **배경·피사체 분리 시작**을 누르면 자동 분리로 실제 전경·배경 레이어를 만들고 인식한 영역을 표시한다.
3. **선택 영역**에서 브러시로 피사체 중심을 대략 그리거나 올가미로 배경을 포함해 둘러싼다. 칠한 범위는 SAM의 위치 힌트이며, **테두리와 반투명 내부 색칠**로 표시한다. 올가미는 드래그하거나 클릭으로 꼭짓점을 추가한 뒤 첫 점 클릭/Enter로 닫는다. 닫기 전 Esc 또는 실행 취소로 취소한다. 지우개는 선택 영역을 뺀다.
4. 아래의 **선택한 영역으로 피사체 적용**을 누르면 그린 영역으로 피사체 경계만 재인식해 표시한다. 실제 레이어는 바뀌지 않는다. 실행 취소·다시 실행·선택 초기화가 가능하다. 아래 버튼은 이전 수정 사항 적용 버튼과 같은 흰 배경·파란 글자 디자인이다.
5. 결과를 확인하고 위의 **배경·피사체 분리 시작**을 다시 눌러야 `/subject-mask`로 원본 크기 마스크를 보내 전경과 LaMa 배경을 갱신한다. 미인식 영역이 있으면 시작 버튼이 잠기고, 아래 버튼으로 인식한 뒤 다시 활성화된다. 지우개로 지운 범위는 재인식 후에도 유지한다. 별도의 피사체 다시 분리·수정 사항 적용 버튼, 브러시 우클릭 지우기, 피사체 선택·제외할 영역 모드 버튼은 제공하지 않는다.
6. 피사체·배경·합성 미리보기와 PNG 다운로드로 확인한다. 미적용 수정이 있는 동안 결과 다운로드를 막는다. 마스크 PNG는 인식이 완료되면 레이어 적용 전에도 받을 수 있다.

자동 분리 전에도 영역을 먼저 그릴 수 있다. 이 경우 아래 버튼으로 선택을 인식한 뒤 위의 시작 버튼으로 실제 레이어를 생성한다. 실패하면 기존 결과와 수정한 마스크를 보존한다. 줌 상태에서는 화면 이동 버튼, Space+드래그 또는 가운데 버튼으로 이동할 수 있다.

## 실행 구조와 격리

```text
로컬 Vite 웹 → localhost SSH 터널 → 별도 SeparationLab API → S3 / RunPod
          └→ Web Worker의 SAM 선택 인식 (WebAssembly CPU)
```

- 테스트 API는 SSH 호스트의 `upscale-separation-labs/<실행ID>/`에서 일시적으로 실행되고 `127.0.0.1`에만 바인딩한다. systemd·Nginx·운영 릴리스는 변경하지 않는다.
- 기존 `ProjectsController`, `ProjectService`, `ProjectProcessingService`, `RunPodImageLayerProcessor`를 재사용한다. 모델 추론을 모의 응답이나 로컬 GPU로 대체하지 않는다.
- 테스트 메타데이터는 xUnit과 동일한 EF Core InMemory provider로 격리한다. 프로세스를 재시작하면 프로젝트 목록은 사라진다. 운영용 PostgreSQL 설정은 전달하지 않는다.
- 바이너리는 기존 S3의 매 실행마다 생성한 테스트 계정 UUID 영역에만 저장한다. 클라우드 중간 파일은 이 테스트 큐가 만든 job ID로 추적한다.
- JWT secret과 12시간짜리 계정 세션을 테스트 프로세스에서 별도로 생성한다. 운영 JWT를 받아들이지 않으며 소유권·세션 검증은 기존 API 구현을 따른다. 클라이언트에는 공급자 자격이 전달되지 않는다. 세션이 만료되면 실험실을 종료하고 다시 실행한다.
- `AWS__*`, `RunPod__*` 설정만 SSH 호스트의 보호된 설정에서 읽는다. 비밀값을 로컬 설정 파일이나 브라우저에 복사하지 않는다.
- 외부 Origin을 거부하고 테스트 전용 요청 헤더를 요구한다. 이 페이지는 Vite 개발 모드에서만 열린다.

### 대략적인 선택을 실제 피사체 경계로 바꾸는 모델

- [SlimSAM 모델](https://huggingface.co/Xenova/slimsam-77-uniform), Apache 2.0, snapshot `5850ab45f587c112167512ffef949107115e26a0`을 고정했다. [Transformers.js 3.8.1 SAM](https://huggingface.co/docs/transformers.js/v3.8.1/api/models#sammodel)과 ONNX Runtime의 WebAssembly CPU를 전용 Web Worker에서 실행한다. 로컬 GPU 실행기나 클라우드 추론 실패 시 대체 경로를 만들지 않는다.
- 모델은 첫 방문에 내려받아 브라우저 캐시에 저장한다. 최초 다운로드에는 인터넷 연결과 대기 시간이 필요하다. 사용자 이미지를 모델 배포 사이트에 업로드하지 않으며, 이미지당 특징 텐서를 캐시해 후속 선택에서 재사용한다.
- 자동 분리 마스크와 대략 그린 범위가 겹치는 피사체 안쪽을 양성 힌트로 고른다. 올가미 바깥의 배경과 지우개 영역은 음성 힌트로 사용한다. 여러 후보에서 힌트·품질·자동 결과와의 일치도를 확인해 선택하며, 칠한 사각형이나 원 자체를 최종 마스크로 사용하지 않는다.
- AI 선택 실패 시 이전 선택을 보존하고 재선택을 안내한다. 다른 이미지의 늦은 응답은 현재 선택에 적용하지 않는다. 실행 취소 분기와 서버 적용 여부를 별도로 추적한다.
- 이 테스트의 선택 모델은 경량 SAM이며, 최초 자동 인식은 BiRefNet, 배경 채움은 기존 LaMa를 유지한다. 복잡한 털·가려진 피사체 등 모든 사진의 품질을 보장하는 모델 교체는 아니다.

## 정리와 종료

화면의 **테스트 파일 정리**는 현재 실행의 프로젝트와 S3 객체를 정리한다. GPU 작업이 진행 중이면 끝난 뒤 정리한다.

실행 시 출력된 `RunDirectory`로 다음을 실행하면 테스트 API·SSH 터널·Vite를 종료하고, 이 실행이 기록한 S3 객체 및 원격 임시 폴더만 제거한다.

```powershell
./web/scripts/separation-lab.ps1 -Stop -RunDirectory 'C:\absolute\workspace\artifacts\separation-lab-...'
```

실행 로그·프로세스 정보는 Git에서 제외된 `artifacts/<실행ID>/`에 남는다. 연결 대기 중 실패한 경우에도 `running.json`이 있는 해당 폴더로 `-Stop`을 실행할 수 있다. 정상적인 종료를 위해 진행 중인 GPU 작업이 끝날 때까지 기다린다. 기존 RunPod endpoint의 실제 추론 비용이 발생한다.

브라우저 새로고침은 화면 작업을 초기화한다. 남길 결과는 먼저 PNG로 다운로드한다. 운영 반영 시에는 별도의 마스크 수정용 DB 마이그레이션 검토·적용이 필요하며, 이 도구는 운영 DB 마이그레이션을 실행하지 않는다.

## 검증 기록 — 2026-10-30

- 웹 TypeScript 및 Vite 빌드 성공. 웹 테스트 68개 통과, 운영 HTTP 검증 15개는 로컬 테스트에서 제외. 실험실 화면은 개발 모드에서만 불러온다. 운영 작업실에도 같은 선택 기능을 연결했으므로 운영 빌드는 선택 AI worker와 WASM 자산을 포함한다. [작업실 적용](../../../docs/smart-subject-selection.md)을 참고한다.
- 백엔드 전체 xUnit 테스트 219개 통과.
- 1,536 × 1,024 여우 샘플로 실제 GPU 자동 분리 성공.
- 브라우저에서 브러시 추가·우클릭/지우개 드래그로 빼기, 올가미 추가·빼기 및 첫 점/Enter로 닫기, Esc 취소와 미완성 올가미 적용 방지, 실행 취소·다시 실행, 전체 선택 비우기 및 빈 선택 요청 차단 확인.
- 수정 마스크를 실제 API로 보내 재분리 성공. 다운로드한 마스크와 새 피사체 PNG의 알파 채널을 **전체 1,572,864픽셀** 비교하여 차이가 0임을 확인. 배경 보기에서 피사체 뒤 영역 채움 확인.
- 테스트 헤더 누락 403, 세션 누락 401, 외부 Origin 403 확인.
- 실제 브라우저에서 배경을 포함한 넓은 브러시와 큰 올가미로 여우만 선택되는 것, 지우개의 음성 힌트로 경계가 바뀌는 것, SAM 선택 뒤 실제 GPU 레이어가 자동 갱신되는 것을 확인했다. 모델 후보의 배경 조각은 양성 힌트와 연결된 영역만 남겨 제거한다.
- 최종 SAM 올가미 결과의 다운로드 마스크와 실제 GPU 전경 알파를 1,572,864픽셀 모두 비교해 차이 0을 확인했다. 넓은 올가미 안의 배경 지점은 선택되지 않았고 피사체 면적은 전체의 17.6371%였다. 피사체 RGB가 원본과 같고, 배경은 불투명하며, 채움 범위 밖의 RGB도 원본과 같음을 확인했다. 증거는 Git에서 제외된 `artifacts/smart-selection-20261030/verification.json`과 PNG·화면 캡처에 있다.

이 검증은 SAM을 이용한 대략적인 선택 재인식과 기존 BiRefNet + LaMa의 레이어 생성 흐름에 대한 것이다. 최초 자동 분리 모델과 배경 생성 모델 자체는 교체하지 않았다.
